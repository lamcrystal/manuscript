# Project 1: *Manuscript*

A styled HTML interpretation and response to Daisy Alioto’s [“Thoughts on Gradients: the colorful design trend aiming to soothe these anxious times”](https://www.vox.com/the-goods/2019/3/1/18241592/gradients-facebook-coachella-daily-fading-pastel-design-trend), originally published in *Vox* in 2019.

The visual design uses Bebas Neue, Space Grotesk, and a gradient background inspired by the subject of the article. The response considers how gradients can communicate meaning beyond aesthetics.

Based on [Project 1: Manuscript](https://typography-interaction-2627.github.io/project/1/).
